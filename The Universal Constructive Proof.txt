2 The C/T/C Cycle

A finite system evolves through the following deterministic sequence:

Construction — Define a set of primitives.
Each primitive is an executable recipe describing its own update rule.
Example: a neuron is represented by its weights, threshold, and firing function.

Tagging — Assign identifiers encoding role and state.
Tagging discretizes otherwise continuous dynamics.
Example: a particle’s tag encodes position, momentum, and spin.

Conversation — Tagged primitives interact through the GMPre algebra using defined operators such as mixers or pulse updates.
These interactions are deterministic exchanges of state information.
Example: attention layers in AI correspond to token–token conversations.

Collapse — The system resolves to the next valid state.
Collapse is the deterministic result of the preceding interactions.
Example: thermodynamic irreversibility corresponds to the stable outcome of microscopic mixing.

Observation: Collapse is not an independent or stochastic event; it is the computed resolution of a deterministic interaction.

class MemoryTag:
    def __init__(self, text, importance):
        self.text = text
        self.importance = importance
        self.age = 0
    def decay(self):
        self.importance *= math.exp(-0.1 * self.age)
        self.age += 1

class SemanticMemory:
    def __init__(self):
        self.tags = []
    def add(self, text, importance):
        self.tags.append(MemoryTag(text, importance))

        for tag in self.tags: tag.decay()
    def snapshot(self):
        active = sorted(self.tags, key=lambda t: t.importance, reverse=True)
        return [t.text for t in active[:3]]
